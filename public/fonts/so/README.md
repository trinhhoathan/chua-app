# Font viết sớ (`public/fonts/so/`)

## Bản quyền — miễn phí thế nào?

Hầu hết font Trung trong thư mục này dùng **SIL Open Font License (OFL) 1.1**:

| Được phép | Không được |
|-----------|------------|
| Dùng cá nhân & thương mại | Bán riêng file font |
| Nhúng web / app / in ấn | Đổi license sang kiểu khác khi phân phối lại font |
| Sửa / tạo font phái sinh (vẫn phải OFL) | |

→ Dùng in sớ trong app này là **hợp lệ**. Giữ file `OFL` gốc nếu redistribute font.

HAN NOM A/B (VietUnicode 2005) và UVN Bo Quen / Han-Nom Kai theo nguồn bộ mẫu sớ — dùng nội bộ dự án.

## Font Quốc ngữ

Dropdown **Font Quốc ngữ** gồm:

| Nhóm | Font |
|------|------|
| Việt / sớ | UVN Bo Quen, Be Vietnam Pro (+ Medium) |
| Serif | EB Garamond, Literata, Lora, Source Serif 4, Spectral, IBM Plex Serif, Libre Baskerville, Alegreya, Cormorant Garamond, Newsreader, Noto Serif, Crimson Pro, Playfair Display |
| Sans | Mulish, Nunito, Inter, Source Sans 3, IBM Plex Sans |
| Hệ thống | Times New Roman, Georgia, Arial |

Các font Google (trừ UVN / hệ thống) là **SIL OFL** — self-host trong thư mục này.
